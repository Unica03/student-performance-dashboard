# Student Performance & Growth Dashboard 🎓

An interactive Power BI dashboard designed to analyze the academic progress, skill development, attendance, and test performance of Class 11 & 12 students.

## 📊 Key Features:
- Academic performance tracking by subject and student
- Skill matrix with conditional formatting to highlight strengths and weaknesses
- Attendance trend line and overall participation metrics
- Mock test performance breakdown with subject-level filtering
- Intelligent course recommendations based on average skill scores and performance categories
- Smart summary using dynamic DAX to highlight top skill, at-risk students, and average scores

## 🧰 Tools & Technologies:
- Power BI
- DAX
- Excel

## 📁 Files Included:
- `StudentDashboard.pbix` – The full interactive dashboard file
- `StudentDashboard.pdf` – Preview of the final dashboard layout
- `README.md` – Project overview and description

## 📎 Project Highlights:
This dashboard uses slicers, cards, measures, conditional formatting, and summary logic to provide a 360° view of a student’s academic and skill-based development. It can be used by educators to monitor individual progress and suggest personalized growth programs.
